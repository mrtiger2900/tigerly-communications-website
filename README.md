# Tigerly Communications — Marketing Website

Static marketing website for Tigerly Communications (Gaborone, Botswana): push-to-talk radios, guard monitoring and the dispatcher platform, body cameras, employee and asset tracking, worker-wellness devices and visitor management.

## Structure
- index.html — single-page site (self-contained, images inlined)
- vercel.json — Vercel configuration (clean URLs)

## Deploy
Static site, no build step. On Vercel, import this repository and deploy with the default settings (framework preset: Other).
